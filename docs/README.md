## 文档使用建议

### 新成员上手
1. 先读 `docs/项目架构总览.md` 了解项目结构
2. 再读 `AGENTS.md` 了解关键技术点
3. 查看 `docs/开发进度跟踪.md` 了解当前状态

### 开发前查阅
- 查看 `docs/开发进度跟踪.md` 确认当前任务
- 参考 `CLAUDE.md` 了解代码规范
- 遵循 `docs/开发计划与优先级.md` 中的优先级

### 使用codex或claude code
- 两个AI工具会自动读取 `AGENTS.md` 作为项目记忆
- `CLAUDE.md` 提供给Claude Code的额外指导
