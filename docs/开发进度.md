## 已完成

### 用户系统（100%）

- 医生端：`DtLogActivity` 登录 / 注册，`Doctor` Entity + DAO + Repository，信息查看与编辑
- 患者端：`PtLogActivity` 登录 / 注册，`Patient` Entity（含 `bindingStatus`）+ DAO + Repository
- 医患绑定：`DoctorTask`、`PatientApplicationActivity`、`WaitingBindingActivity`
- 绑定状态：`unbound → pending → active / rejected`

### 主界面框架（100%）

- 医生端 `DtHomeActivity`：首页 / 患者管理 / 个人信息
- 患者端 `PtMainActivity`：首页 / 康复中心 / 个人信息
- Navigation Component + BottomNavigationView，双端导航图与参数解析已统一

### 康复计划数据层（100%）

- 4 个 Entity：`RehabPlan`、`TrainingTask`、`TaskInstance`、`PlanAdjustment`
- 4 个 DAO + 4 个 Repository
- `TaskInstance` 唯一索引 `(taskId, patientId, scheduledDate)`
- 数据库 v8，共 10 张表

### 医生端康复计划 UI（100%）

- `CreateRehabPlanActivity` + ViewModel：计划信息、添加 / 删除任务、频率设置、保存草稿 / 激活
- `RehabPlanListFragment` + `PatientPlanGroupAdapter`：按患者分组、展开 / 收起
- 患者管理页集成创建计划入口

### 任务自动生成（100%）

- 入口：`TaskInstanceRepository.generateDailyTasks(patientId, date)`
- 频率规则：`utils/TaskSchedule.kt` 纯函数 `shouldGenerate(task, planStartDate, date)`
  - `daily`：计划窗口内每天
  - `weekly`：`frequencyDetail` 如 `"1,3,5"`，1=周一、7=周日
  - `interval`：`frequencyDetail` 如 `"2"`，从计划开始日算起
- 触发点：患者登录成功、`PtMainActivity.onResume`
- 去重：业务预检 + 唯一索引 + `OnConflictStrategy.IGNORE`
- 只生成当天，不补历史；异常不阻断登录

### 患者端任务执行（列表与完成 / 跳过已通）

- 今日任务列表接真实 `TaskInstance`，按状态展示徽标与入口
- 待完成任务可“开始”，弹“完成 / 跳过 / 取消”
- 完成 / 跳过走 `TaskExecutionRepository`，在 `db.withTransaction` 内更新状态、写时间戳、重算计划进度
- 今日进度：文字“已完成 / 总数”+ 横向 `ProgressBar`（不是环形图）
- 本周柱状图：周一至周日七天真实完成 / 总数，标记今天
- 本周完成卡真实；“累计训练”“连续打卡”显示 `--`
- 患者首页与康复中心共用 `PtMainActivity` 作用域的 `PtRehabViewModel`，数字同源

### 状态与数据规则（2026-11-10，100%）

## 已知问题 / 风险

1. **数据库破坏性迁移**：开发期使用 `fallbackToDestructiveMigration()`，升级清空数据；发布前必须补 Migration
2. **冗余统计字段**：`Patient.todayTasksCompleted`、`weeklyCompletionRate` 等需手动更新，容易漏
3. **测试覆盖不均**：频率、进度、状态映射、任务执行事务有单测；视频、审核尚未实现，自然没有覆盖
4. **安全债**：密码明文、数据库未加密；DeepSeek Key 已从源码移到 `local.properties`，但历史提交中的旧 Key 仍需轮换
5. **本地单设备**：医生 / 患者必须切账号演示，两台设备不同步
6. **界面自动化偶发超时**：机器负载高时偶发登录后等 `doctorHomeRoot` 超时，属等待时间不足，重跑即可；跑前先唤醒模拟器
7. **Lint warning 284 条**：错误已清零，warning 未逐条处理（多为未使用资源 / 硬编码文案等非阻塞项）
8. **视频存储未设计**：当前只有本地路径字段，没有上传、云端、清理策略
