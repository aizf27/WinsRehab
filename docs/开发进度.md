## 已知问题与风险

- Room 当前为 v8，使用 `fallbackToDestructiveMigration()`，升级可能清空演示数据。上线前补 Migration。
- 密码明文存储，数据库未加密。真实患者数据上线前需要认证、访问控制和数据保护。
- DeepSeek Key 由配置经 `BuildConfig` 注入。历史提交中的旧 Key 需轮换，客户端 APK 中的 Key 也可被提取，发布前需要调整密钥方案。
- `Patient` 保留历史冗余统计字段。页面统计以行为契约规定的查询为准，避免新增第二套来源。
- 界面测试偶发等待 `doctorHomeRoot` 超时。先确认模拟器已唤醒并复跑，持续失败时保留日志排查。
