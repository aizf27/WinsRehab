## 🧪 测试用例

### 测试1：首次登录生成任务

**前置条件**：
- 数据库中有test001患者
- 有一个active状态的康复计划
- 计划中有3个不同频率的任务模板
- task_instance表为空（该患者无任务实例）

**测试步骤**：
1. 启动应用
2. 使用test001/123456登录
3. 观察Logcat日志

**预期结果**：
- Logcat显示："开始生成任务: patientId=test001, date=2026-09-07"
- Logcat显示："找到1个活跃计划"
- Logcat显示："计划[测试康复计划]有3个任务模板"
- 根据今天星期几，生成对应任务：
  - daily任务：每天都生成
  - weekly任务：如果今天是周一/三/五则生成
  - interval任务：首次生成（lastDate=null）
- Logcat显示："批量插入N个任务实例成功"（N=2或3）
- 数据库task_instance表中新增对应记录

**验证方法**：
```sql
-- Android Studio -> Database Inspector
SELECT * FROM task_instance WHERE patientId = 'test001' AND scheduledDate = '2026-09-07';
```

**验证字段**：
- instanceId：自动生成
- taskId：对应任务模板ID
- patientId：test001
- scheduledDate：2026-09-07
- status：pending
- completedAt：null
- videoId：null

### 测试2：重复登录去重

**前置条件**：
- 测试1已完成，task_instance表中有今日任务

**测试步骤**：
1. 退出登录（回到登录页）
2. 再次使用test001/123456登录
3. 观察Logcat日志

**预期结果**：
- Logcat显示："任务[XXX]已存在，跳过"
- Logcat显示："没有需要生成的任务" 或 "批量插入0个任务实例"
- 数据库task_instance表记录数量不变
- 无重复记录

**验证方法**：
```sql
-- 检查是否有重复
SELECT taskId, scheduledDate, COUNT(*) as count
FROM task_instance
WHERE patientId = 'test001' AND scheduledDate = '2026-09-07'
GROUP BY taskId, scheduledDate
HAVING count > 1;
-- 结果应为空
```

### 测试5：weekly频率验证

**目标**：验证周一三五生成，其他日期不生成

**测试数据**：
- frequencyDetail = "1,3,5"
- 今天是2026-09-07（周日）

1. 清空task_instance表
2. 修改系统日期测试不同星期几：
   - 09-08（周一，dayOfWeek=1）→ 应生成
   - 09-09（周二，dayOfWeek=2）→ 不生成
   - 09-10（周三，dayOfWeek=3）→ 应生成
   - 09-11（周四，dayOfWeek=4）→ 不生成
   - 09-12（周五，dayOfWeek=5）→ 应生成
   - 09-13（周六，dayOfWeek=6）→ 不生成
   - 09-14（周日，dayOfWeek=7）→ 不生成

**预期结果**：
- 只在周一、三、五生成weekly任务
- Logcat显示对应的频率判断日志

### 测试6：interval频率验证

**目标**：验证间隔天数计算正确

**测试数据**：
- frequencyDetail = "2"（间隔2天）

**测试步骤**：
1. 清空task_instance表
2. 09-07登录 → 首次生成（lastDate=null）
3. 09-08登录 → 间隔1天，不生成
4. 09-09登录 → 间隔2天，应生成
5. 09-10登录 → 距离09-09间隔1天，不生成
6. 09-11登录 → 距离09-09间隔2天，应生成

**预期结果**：
- 09-07、09-09、09-11有interval任务
- 09-08、09-10没有interval任务

**验证SQL**：
```sql
SELECT scheduledDate, COUNT(*) 
FROM task_instance 
WHERE patientId = 'test001' AND taskId = <interval任务的taskId>
GROUP BY scheduledDate
ORDER BY scheduledDate;
```
