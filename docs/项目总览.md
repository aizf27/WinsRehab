# WinsRehab 项目总览

WinsRehab 面向康复科医生、理疗师及居家康复患者。主线覆盖医患绑定、计划、训练任务、视频审核与反馈。实际实现范围见 [开发进度](./开发进度.md)，后续范围见 [开发计划](./开发计划.md)。

## 技术架构

- Kotlin、MVVM、ViewBinding、Material Components、Navigation Component。
- Activity / Fragment + ViewModel → Repository（业务逻辑与事务）→ Room DAO / Entity。界面观察 `LiveData` 或 `Flow`。
- 心理助手使用 OkHttp / Gson 调用 DeepSeek。SDK、依赖与构建配置以 `app/build.gradle.kts` 为准。

## 数据模型

| 领域 | 模型与关系 |
|---|---|
| 医患绑定 | `Doctor` 通过 `doctorCode` 关联 `Patient`。`DoctorTask` 存医生待办和绑定申请。 |
| 计划与任务 | `RehabPlan` 包含 `TrainingTask` 模板，按频率生成 `TaskInstance`。`PlanAdjustment` 存调整记录。 |
| 视频与反馈 | `PtRehabVideo` 存患者视频路径、任务关联与审核元数据。`DemoVideo` 是独立的示范视频库。`Feedback` 存计划反馈。 |

Room 表和版本以 `AppDatabase` 为准。`ChatMessage` 是心理助手的聊天模型。状态常量在 `data/model/Status.kt`。业务转换、统计公式和日期边界集中在 [行为契约 §1](./行为契约.md#1-任务与计划)。

## 页面和代码入口

`SelectLogActivity` 负责选择角色。医生经 `DtLogActivity` 到 `DtHomeActivity`，患者经 `PtLogActivity` 和绑定流程到 `PtMainActivity`。

| 模块 | 定位关键词 |
|---|---|
| 医生端 | `DtHomeActivity`、`PatientApplicationActivity`、`CreateRehabPlanActivity`、`RehabPlanListFragment` |
| 患者端 | `PtMainActivity`、`WaitingBindingActivity`、`PtRehabViewModel`、`TrainingVideoActivity`、`VideoPlayerActivity`、`PsychologyActivity` |
| 任务调度 | `PtLogVM`、`PtMainActivity.onResume`、`TaskInstanceRepository`、`TaskSchedule` |
| 任务执行与统计 | `TaskExecutionRepository`、`PlanProgress`、`DateRanges` |

主代码位于 `app/src/main/java/com/example/winsrehab/`。`data/` 放实体、DAO、Repository、状态模型和数据库，`ui/main/` 按角色组织界面，`ui/common/` 放共享组件、状态映射及页面参数解析，`utils/` 放日期、调度、进度和演示数据工具。

界面语义资源在 `app/src/main/res/values/`。界面及导航验收规则见 [行为契约 §3–4](./行为契约.md#3-界面基线)。
