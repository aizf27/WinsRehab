## 目标

构建**医患协作的康复管理闭环**：医生创建计划 → 系统生成任务 → 患者执行并录视频 → 医生审核 → 患者查看结果。

MVP 验收标准：以上闭环完整跑通，杀进程后状态不丢。

## 已知问题 / 风险

1. **interval 节奏会漂移**：依赖 `getLastScheduledDate()`，漏签或补生成会让间隔基准变化；新计划要求纯函数 `(task, planStartDate, date)`
2. **没有自动化测试**：频率规则、状态流转、去重都靠手测
3. **数据库破坏性迁移**：`fallbackToDestructiveMigration()`，升级清空数据
4. **统计字段手动更新**：`todayTasksCompleted`、`weeklyCompletionRate` 容易漏
5. **周统计边界**：`getWeekDateRange()` 的周日边界待修
6. **安全债**：密码明文、数据库未加密；API Key 已外置，但历史泄露的旧 Key 仍需轮换
7. **本地单设备**：医生/患者切账号演示，两台设备不同步
